# baton 1.0.0-beta.2 — 첫 공개 릴리스 (초안)

> 릴리스 노트 초안입니다. 태그 `v1.0.0-beta.2`와 GitHub 릴리스는 저장소 소유자가 만듭니다.

새 세션마다 "어디까지 했더라"를 다시 설명하지 않게 해 주는 Claude Code 플러그인의 첫 공개 릴리스입니다.
인계서(`HANDOFF.md`)를 저장하는 순간 빠진 절·비밀값을 잡아 주고, 다음 세션에서 "이어서"라고만 치면 그 인계서를 맥락에 넣어 줍니다.

## 30초 설치

Claude Code 안에서:

```
/plugin marketplace add sulabo/baton
/plugin install baton@baton
```

필요한 것은 `git`과 `python3`뿐입니다. 새 세션에서 `/baton-doctor`로 준비 상태를 보고, 한 번 `/baton-setup`을 돌리면 내 기록으로 문턱을 맞춥니다.
Codex(0.155 이상)는 `codex plugin marketplace add sulabo/baton` → `codex plugin add baton@baton`.

## 이번 판에서 처음 쓸 수 있는 것

- **`/baton-setup`** — 내 세션 기록과 git 이력을 읽기만 해서 알림 문턱·인계서 트리거 말·개인 자료 차단 목록을 제안하고, 고른 것만 `~/.config/baton/config.json`에 씁니다.
- 인계서 검사가 내가 고른 개인 자료 단어(이름·이메일 등)도 막습니다.
- `1.0.0-beta.1`에서 들어온 것: 인계서 저장 시 검사, 파일 3개 이상 고친 뒤 인계서 제안, Codex에서도 맥락에 들어가는 JSON 출력, 관찰 로그를 지우던 캐시 정리 버그 수정.

## 실사용에서 잰 것 (만든 사람 한 명)

- "이어서·어디까지"로 시작한 세션에서 에이전트가 첫 5호출 안에 인계서를 다시 연 세션: **설치 전 42개 중 41개 → 설치 뒤 11개 중 3개**(그중 2개는 일부만).
- 7주 동안 인계서 주입 270번, 인계서 저장 시 검사 38번 중 20번 문제를 돌려줌.
- **세션 앞쪽 토큰은 줄지 않았습니다.** 같은 기간 고정 맥락이 커져 효과를 분리하지 못했습니다. 스냅샷 실험에서는 상태 질문 입력 토큰이 40~54% 줄었습니다.

측정 명령과 출처는 [CHANGELOG](../../CHANGELOG.md)에 있습니다.

## 알려진 한계

- 베타입니다. 효과 수치는 만든 사람 한 명의 기록과 스냅샷 실험에서 나왔습니다.
- 인계서 검사기는 일부 비밀값 형식(`postgres://user:pw@host`, `npm_`·`hf_` 토큰, JWT가 아닌 Bearer 값)을 놓치고, 긴 `sk-` 브랜치 이름 같은 것을 잘못 잡습니다.
- Codex에서는 세션 끊기 알림·인계서 제안·저장 시 자동 검사가 돌지 않습니다.
