# baton 1.0.0-beta.3 — 같은 인계서는 세션에 한 번

**Stop your AI agent from re-reading your project every new session.**
A one-page handoff (`HANDOFF.md`) goes into the next session when you ask to continue, once, with a line that says how old it is. A concept map (`CONCEPTS.md`) ties each concept to its files, so only concepts whose files changed get a second look.
The plugin's messages are in Korean. English overview: [README.md](https://github.com/sulabo/baton#readme).

AI가 새 대화마다 프로젝트를 처음부터 다시 읽지 않게 하는 Claude Code 플러그인입니다.
지난 대화는 인계서 한 장으로 넘기고, 바뀐 곳은 개념 지도로 찾습니다.

## 30초 설치

Claude Code 안에서:

```
/plugin marketplace add sulabo/baton
/plugin install baton@baton
```

이미 설치했다면 터미널에서 `claude plugin marketplace update baton` → `claude plugin update baton@baton`을 돌리고 창을 새로 엽니다. 열려 있던 창은 옛 훅을 계속 씁니다. Codex는 `codex plugin marketplace upgrade baton`.
필요한 것은 `git`과 `python3`뿐입니다. Codex(0.155 이상)는 `codex plugin marketplace add sulabo/baton` → `codex plugin add baton@baton`.

## 이번 판에서 바뀐 것

- **같은 인계서는 한 세션에 한 번만 넣습니다.** `HANDOFF.md`가 바뀌었거나 대화가 압축됐을 때만 다시 넣습니다. 전 판은 같은 세션에서도 "이어서" 같은 말이 나오거나 다른 세션·작업 알림 메시지에 그 말이 섞일 때마다 다시 넣어서, 만든 사람의 실사용(10-04~11-19)에서 39개 세션에 269번 들어갔습니다(세션 첫 프롬프트에 들어간 것은 32번뿐). 다른 세션·서브에이전트 메시지와 작업 알림에는 넣지 않습니다.
- **인계서에 신선도 한 줄을 붙입니다.** 작성일, 며칠 전인지, 그 뒤 이 폴더에 들어온 커밋 수를 적고, 7일이 지났으면 다음 행동이 아직 맞는지부터 보라고 적습니다. 셀 수 없으면 "없다"가 아니라 못 셌다고 적습니다.
- **검사를 통과한 인계서는 잘리지 않습니다.** 검사 상한을 8,700자로 낮추고 훅 출력 상한을 9,600자로 올렸습니다(Claude Code 문서의 훅 출력 상한 10,000자 아래).
- **개념 색인.** `CONCEPTS.md`가 있으면 세션의 첫 프롬프트에 개념 목록(이름·주요 파일, 1,500자 이하)을 한 번 넣습니다. 끄기: `BATON_CONCEPT_INDEX=off`.
- `HANDOFF_트랙.md`처럼 이름 붙은 인계서를 써도 인계서 제안에서는 쓴 것으로 칩니다.
- 소개 문구와 README를 인계서·개념 지도 두 가지 중심으로 다시 썼습니다.
- 개념 지도를 키우는 도구가 들어왔습니다. 지난 세션에서 별칭 후보를 찾는 `lib/candidates.py`, 프롬프트마다 볼 개념을 골라 보여 주는 `lib/compiler.py explain`, 지도를 옵시디언 노트로 바꾸는 `lib/notes.py`입니다. 셋 다 직접 돌리는 도구이고, 훅에는 붙어 있지 않아 에이전트가 보는 것은 바꾸지 않습니다.

## 아직 확인하지 못한 것

- **실사용에서 토큰이 줄었는지는 아직 모릅니다.** 전 판에서는 줄지 않았고(대화 첫 호출들이 오히려 더 들었고, 같은 기간 다른 플러그인·지침도 커져 효과를 떼어 내지 못함), 이번 판을 설치한 뒤의 기록은 아직 없습니다.
- **개념 색인의 효과는 결론을 못 냈습니다.** 24번 돌린 시험(일상어 질문 4개 × 3번 × 색인 있음·없음)에서 정답 파일을 처음 겨냥한 순번은 평균 1.50 대 2.33으로 색인 쪽이 빨랐지만, 4개 질문 중 2개에서만 나았습니다.
- **별칭 후보는 만든 사람의 기록으로 0건이었습니다.** 사람이 쓰는 말과 개념 이름을 맞추는 별칭은 지금은 사람이 직접 붙여야 합니다.

## 알려진 한계

- 베타입니다. 수치는 만든 사람 한 명의 기록에서 나왔습니다. 실사용 269번은 저장소 4곳의 기록이지만 그중 한 곳이 255번이고, 24번 시험은 저장소 하나에서 했습니다.
- 신선도 줄의 커밋 수와 `/drift`는 커밋된 이력만 봅니다. 커밋하지 않은 변경은 잡히지 않습니다.
- 메시지·스킬은 한국어입니다. 영어 "continue" 한 단어는 인계서 주입 트리거가 아닙니다(`/baton-setup`으로 추가).
- 한 번만 넣기에는 사각지대가 있습니다. `/rewind` 뒤에는 인계서가 맥락에 있다고 보고 다시 넣지 않습니다. 그때는 AI가 파일을 직접 읽습니다.
- 인계서 검사기는 일부 비밀값 형식(`postgres://user:pw@host`, `npm_`·`hf_` 토큰, JWT가 아닌 Bearer 값)을 놓칩니다.
- Codex에서는 새로 시작하라는 알림·인계서 제안·저장 시 자동 검사가 돌지 않습니다.
