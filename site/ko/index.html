AI가 새 대화마다 프로젝트를 처음부터 다시 읽지 않게.

어제 한 일을 설명하느라 오늘 토큰을 쓰지 않아도 돼요. 새 대화를 열면 AI가 멈춘 곳과 다음 할 일부터 말해요.

/plugin marketplace add sulabo/baton
GitHub에서 보기

Claude Code와 Codex에서 써요. git과 python3가 필요해요. 무료 오픈소스예요(MIT).

문제

대화가 길어질수록, 비용은 대부분 후반에 나가요.

AI를 부를 때마다, 그때까지 나눈 대화가 전부 다시 들어가요. 그래서 대화가 길어질수록 같은 일도 비싸져요. 새 대화를 열면 가벼워지지만, AI는 어디까지 했는지 찾느라 지난 기록부터 다시 열어요.

42개 중 41개 → 11개 중 3개진행 상황을 물으며 시작한 대화 중, AI가 첫 5번 호출 안에 인계서를 다시 연 대화예요. baton 설치 전 → 설치 후. 일부만 읽은 대화는 설치 전 3개, 설치 후 2개예요.

실제 사용, 설치 전 08-31~10-04 · 설치 후 10-19~11-20. 설치 후는 대화가 11개뿐이라 방향만 보여 줘요. 같은 대화들에서 첫 5번 호출의 입력 토큰은 오히려 339–404K → 446–494K로 늘었어요(주별 중앙값). 자세한 숫자는 아래 "지금까지 잰 것"에 있어요.

작동 방식

대화가 바뀌어도, 일은 이어져요.

  1. 1 · 대화를 마칠 때

    작업을 끝내면, AI가 인계서 한 장을 남겨요.

    저장하는 순간, 비밀번호나 빠진 항목이 없는지 검사해요.

    Claude Code에서는 파일을 3개 이상 고치면 baton이 AI에게 인계서(HANDOFF.md)를 갱신하라고 해요. "인계서 써 줘"라고 해도 돼요. 검사는 정해진 때에 도는 스크립트(훅)가 해요.

  2. 2 · 다음 대화

    다음 대화는, 그 한 장에서 시작해요.

    "어디까지 했지?"라고 물으면, AI가 파일을 뒤지기 전에 그 한 장을 받아요.

    한 대화에 한 번 넣어요. 언제 썼는지, 그 뒤 커밋(저장소에 남긴 변경)이 몇 개인지도 함께 알려 줘요.

  3. 3 · 코드가 바뀐 뒤

    코드가 바뀌면, 다시 볼 곳을 알려 줘요.

    새 대화를 열 때, 다시 볼 곳이 몇 군데인지 한 줄로 보여 줘요.

    아래에서 설명하는 개념 지도(CONCEPTS.md)에 이름마다 파일과 마지막으로 확인한 커밋을 적어 두고, git 기록으로 세어 봐요. 자세한 표는 /drift.

개념 지도

바뀐 개념만 다시 봐요. 나머지는 건너뛰어요.

게임의 "목숨", "점수"처럼 프로젝트에서 부르는 이름마다, 관련 파일과 마지막으로 확인한 때를 적어 둬요(CONCEPTS.md). 새 대화를 열면 AI가 이 목록을 먼저 받아요. 이름마다 주로 넷 중 하나가 붙어요.

  • 신선확인한 뒤로 파일이 그대로예요. 건너뛰어도 돼요.
  • 커밋 N건확인한 뒤로 파일을 바꾼 커밋이 N건 있어요. 다시 봐요.
  • 기준 없음확인한 기록이 아직 없어요. 그래서 그대로라고 치지 않아요.
  • 문서 커밋 N건코드는 그대로인데, 그 코드를 설명하는 문서가 바뀌었어요.

지금까지 잰 것

실험에서는 토큰이 줄었어요. 실제 사용에서는 아직이에요.

모두 만든 사람 한 명이 자기 저장소에서 잰 숫자예요. 실제 사용은 평소에 쓴 대화의 기록이고, 실험은 같은 저장소 상태에서 조건만 바꿔 되풀이한 결과예요. 조건과 출처는 README의 결과 표에 있어요.

40–54%

진행 상황을 물을 때 인계서를 넣었더니 줄어든 입력 토큰이에요. AI가 일을 마치기까지 주고받은 횟수도 중앙값 5–6번에서 3번으로 줄었어요.

실험. 저장소 3곳, 조건마다 3~5번.

+11%

관련 없는 작업에 인계서를 넣었더니, 입력 토큰이 오히려 이만큼 늘었어요.

실험. 저장소 1곳, 5번. 그래서 물어볼 때만 넣어요.

$1.00 → $0.68

대화 한 번의 평균 비용이에요. 인계서 없이는 $1.00이었고, 인계서 한 장 전체를 넣으면 $0.68이었어요. 줄인 요약 카드만 넣으면 $0.88–1.05였고, AI가 5번 모두 파일을 다시 열었어요.

실험, API 가격 환산. 저장소 1곳, 조건마다 5번, 2026-09. 전체·카드 실험은 기준 실험 뒤에 따로 돌렸어요. 그래서 baton은 요약이 아니라 한 장 전체를 넣어요.

61–71K → 77–87K

실제 사용에서 대화 첫 호출에 담긴 대화 양이에요. 줄지 않고 늘었어요. 같은 기간에 다른 플러그인이 처음부터 차지하는 양도 커져서, baton 몫을 떼어 보지 못했어요.

따로 찾은 문제도 있었어요. 같은 인계서가 대화 39개에 269번 들어갔어요(대화를 시작할 때 들어간 건 32번). 지금은 대화마다 한 번만 넣고, 그 효과는 아직 재지 못했어요.

주별 중앙값, 설치 전 08-31~10-04 · 설치 후 10-19~11-20. 인계서 횟수는 10-04~11-19.

다른 도구와 함께

/compact는 그대로 쓰세요. baton은 새 대화를 맡아요.

  1. 인계서는 이어서 하자고 할 때만 넣어요

    보조 AI(서브에이전트)나 다른 대화가 보낸 메시지에는 넣지 않아요.

  2. AI가 아니라 규칙이 검사해요

    마지막으로 커밋한 판에 있던 줄이 빠져도 알려 줘요. 실패한 방법이나 결정이 말없이 사라지지 않게요.

  3. 결정, 코드, 문서가 어긋난 곳을 짚어요

    정해 두고 아직 안 만든 것처럼, 셋이 서로 다른 말을 하는 곳을 개념마다 표시해요.

2026-11-21과 11-22에 살펴본 도구 중, 이 세 가지를 문서에 적어 둔 곳은 없었어요. 전체 비교 보기

설치

두 줄로 설치하고, "어디까지 했지?"라고 물어보세요.

/plugin marketplace add sulabo/baton
/plugin install baton@baton

Claude Code 안에서 실행하세요. 그다음 새 대화를 열고 /baton-doctor를 실행하세요.

codex plugin marketplace add sulabo/baton
codex plugin add baton@baton

Codex 0.155 이상에서 돼요. 플러그인 훅을 '신뢰함'으로 표시해야 훅이 돌아가요.

설치하기 전에.

baton이 인터넷으로 무언가를 보내나요?

아니요. 훅은 git 기록과 내 컴퓨터의 파일만 읽고, ~/.cache/baton/ 아래에만 써요.

토큰이 줄어드나요?

실험에서는 진행 상황을 물을 때 40–54% 줄었어요. 실제 사용에서는 아직 줄지 않았어요. 조건은 위의 "지금까지 잰 것"에 있어요.

/compact나 /resume과 뭐가 달라요?

/compact는 지금 대화를 요약해서 이어 가고, /resume은 지난 대화를 다시 열어요. 둘 다 대화 하나를 계속 이어 가요. baton은 새 대화를 열 때 써요. 대화 양이 25만 토큰, 45만 토큰을 넘었고 마지막 인계서 뒤에 한 일(파일 고침, 파일을 쓰는 명령, 맡긴 일 속 고침)이 있으면 AI가 인계서를 써 두게 하고(Claude Code), 다음 대화에 직접 읽고 고칠 수 있는 한 장을 건네요. 작업이 끝난 시점에서 맞대 본 실험(미리 짠 대화, 저장소 2곳, 5번씩)에서는 고친 뒤 둘 다 다음 작업을 맞게 이어 갔고, 비용은 /compact가 덜 들었어요. 인계서 쪽이 1.1–1.7배였고, 인계서를 쓰는 데만 compact 한 번의 약 2–3배(중앙값)가 들었어요.

어떤 말을 하면 인계서가 들어가나요?

"이어서", "어디까지", "인계", "handoff" 같은 말이 프롬프트에 있으면 들어가요. 그런 말이 없으면 넣지 않아요. 이런 말은 /baton-setup에서 더 추가할 수 있어요.

DECISIONS.md가 꼭 있어야 하나요?

아니요. 파일이 바뀌었는지는 git 기록만으로 알 수 있어요. 다만 결정 기록이 없으면 "정했는데 아직 안 만든 것"은 찾지 못해요. 파일이 없는 개념도 추적하지 않아요.

내 파일을 바꾸나요?

네, HANDOFF.md는 바뀔 수 있어요. Claude Code에서는 파일을 3개 이상 고치거나, 마지막 인계서 뒤에 한 일(파일 고침, 파일을 쓰는 명령, 맡긴 일 속 고침)이 있는 채로 대화가 25만·45만 토큰을 넘으면 baton이 AI에게 이 파일을 갱신하라고 해요. 제안만 받고 싶으면 BATON_HANDOFF_AUTO=off로 꺼요. CONCEPTS.md는 요청할 때만 AI가 써요. 훅이 직접 파일을 고치지는 않고, 커밋도 하지 않아요.
